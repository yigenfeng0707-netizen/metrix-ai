为什么是 Metrix AI

本届主题是"AI 从聊天工具进化为会管钱、能交易的自主经济主体"——我们就是答案本身。

🧠

确定性策略引擎，LLM 不碰钱

信号全部来自可回测的确定性规则，LLM 只做自然语言解析。每个决策可解释、可复现。

  • 网格策略：格位穿越触发，GTC postOnly 做市
  • 均值回归：VWAP±kσ 反向入场 + EMA 趋势过滤
  • ML 信号：PyTorch LSTM 方向分类（GPU 训练）
🛡️

六条硬风控，代码兜底

风控上限硬编码在服务端，UI 只能调严不能调松。这是"可托付"的前提。

  • R1 单笔 ≤ 净值 5% · R2 敞口 ≤ 30%
  • R3 日亏 -3% 熔断 · R4 回撤 -10% 强平
  • R5 链上滑点强制 · R6 幂等 + 限频
🔗

全链上可验证

现货走 Kuru 官方 SDK，每一笔都落在 Monad 公开订单簿合约上；决策理由与 tx hash 绑定存档。

  • 信号快照 → 规则命中 → 风控裁决 → tx 链接
  • 移动端 PWA 实时决策流
  • PostgreSQL write-through 持久化
