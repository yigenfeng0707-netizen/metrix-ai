## 一、逐镜头脚本

### SHOT 1 ｜ 0:00–0:20 ｜ 痛点开场（悬念）
- **画面**：黑屏打字机效果："你的 AI 能写代码、能聊天——" → 停顿 → "但它敢真金白银地下单吗？" → 切 Metrix AI Logo
- **旁白**：「大模型会聊天、会写代码，但它敢真金白银地下单吗？在 Monad 上，我们把一个 AI Agent 真正接入了交易市场——这就是 Metrix AI。」
- **字幕**：Metrix AI — The agent that doesn't just chat, it trades.

### SHOT 2 ｜ 0:20–0:50 ｜ 充值与启动（Home 屏）
- **画面**：手机画面为主（居中放大），演示：连接钱包 → 输入充值金额 50 USDC → 确认 → 金库净值刷新 → 切换风险档位
- **旁白**：「用户向 Agent 金库充值，选定风险偏好，Agent 立即开始 7×24 自主交易。现货在 Kuru 全链上订单簿执行——每一步都在 Monad 主网，链上可查。」
- **要点**：充值 tx 的浏览器弹窗停留 2 秒（可读出 hash 前 8 位）

### SHOT 3 ｜ 0:50–1:40 ｜ 实时决策流 + 审计（Trade 屏，全片核心）
- **画面**：电脑屏幕 Trade 屏实时滚动；**手动点开一笔决策卡片**放大展示四行结构：信号快照 → 触发规则 → 风控检查 ✅ → tx hash；**点击 tx hash 跳转 Monad 浏览器**，展示真实成交记录（时间戳、金额）
- **旁白**：「这是 Agent 的实时决策流。每一笔交易前，风控引擎先做六项检查；成交后，决策理由和链上凭证绑定在一起。注意——这不是模拟盘，这笔交易刚刚发生在 Monad 主网上，任何人都可以在浏览器里验证。」
- **要点**：镜头停留 ≥8 秒在浏览器成交记录上；音效"叮"配在成交卡片出现时

### SHOT 4 ｜ 1:40–2:20 ｜ 自然语言指挥 + 熔断演示（Chat 屏）
- **画面**：输入「回撤超过 5% 就全平」→ 确认卡片出现 → 点击批准 → 回执；随后展示风控事件：日亏损熔断卡片（R3 触发，Agent 状态变"已熔断"）
- **旁白**：「用户可以直接用一句话指挥 Agent。解析成结构化参数，确认后才执行。更关键的是风控：当日内亏损达到 3%，Agent 自动停止开新仓；最大回撤 10%，无条件全平并暂停。LLM 永远不碰交易决策，也永远不能放松风控。」
- **要点**：熔断是全片记忆点，给 RiskEvent 卡片 4 秒特写

### SHOT 5 ｜ 2:20–3:00 ｜ 架构收尾 + 行动号召
- **画面**：切项目主页（本仓库 docs/index.html）：滚动展示架构图 → 奖金路径表 → GitHub 按钮
- **旁白**：「三套确定性策略、六条硬风控、双 venue 执行——现货走 Kuru，永续走 Perpl，全程链上可验证。完整代码已开源，欢迎评审复现。Metrix AI：不止会聊天，它会交易。」
- **字幕**：Track 01 · Kuru × Perpl · Monad 143 · github.com/…
